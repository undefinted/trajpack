# H100 集群轨迹效用 smoke 复现（2026-08-20）

[English](cluster-h100-20260820.md) | [简体中文](cluster-h100-20260820.zh-CN.md)

这是一次真实的单张 NVIDIA H100 PCIe、严格离线集群运行。它在这一项合成
计算器协议上，独立复现了本地 RTX 4060 结果的方向。它**不能**证明轨迹
普遍更好，也不涉及恢复隐藏模型推理。

| 实验臂 | Tool JSON | 精确表达式 | 可执行结果 | 最终答案 | 工具闭环 E2E |
| --- | ---: | ---: | ---: | ---: | ---: |
| Base | 0/32 | 0/32 | 0/32 | 0/32 | 0/32 |
| Answer-only SFT | 0/32 | 0/32 | 0/32 | 1/32 | 0/32 |
| Complete trajectory SFT | **32/32** | **27/32** | **31/32** | **31/32** | **31/32** |

三臂使用同一输入文件、模型 revision、seed 和 60-step 配置。完整
action → observation → answer 视图在 32 个 held-out 任务上全部生成了合法、
可执行的工具调用，并完成 31 个闭环；answer-only 没有学会工具调用，只答对
1 个任务。此前 RTX 4060 运行的完整轨迹臂为 32/32、answer-only 工具闭环
仍为 0/32，因此结果方向在不同 GPU、PyTorch/CUDA 软件栈和全新离线运行中
得到了复现。

两次运行并非逐位相同：实验源码树哈希不同，其中包括集群上使用的“缺少
`git` 时仍保留 source-tree hash”的健壮性修复。因此这里只称为方向性的
工程复现，不声称跨硬件确定性等价。

## Raw-to-export 邻接验证

运行前重新生成了合成 DeepSeek Harness demo。完整的 raw → canonical →
隐私/质量检查 → 审批 → `deepseek_epoch_sft` 产物树被复制到同一集群持久卷，
20 个根清单条目和 10 个 HF/TRL checksum 全部通过，其中：

- JSONL：`2594bc5c25d0e9c3c31449b12ac21938c8b9f3abb0cd02ce133a02295fa4a341`
- 原生 Parquet：`dd480380ea63060fe641cbc0bf7994fd3119db17258d695557c3681b9faddfca`
- Lineage：`1337d0f6a2ab315b2bda126fe6f8a864e51dfa1bbb8bed672a0f672f6bf2d3ae`

这证明审阅后的导出产物可以跨机器完整传输，但它们**不是**上述效用实验的
训练输入。效用实验使用的是 manifest 中记录的计算器 fixtures。要真正贯通
同一份 DeepSeek 导出数据，还需实现版本固定的训练 renderer，完整处理顶层
tool schema、`reasoning_content` 和组件级 `training_targets`；静默丢字段不能
算作成功。

## 启动阶段保留的失败

1. 集群 chart 从 `alpha` 更新为 `med`，GPU values schema 也发生变化。首次
   渲染得到的是 CPU-only Pod，CUDA 预检阻止了训练。
2. Pod 无法访问 Hugging Face。随后从本地缓存传入固定 snapshot、校验权重
   hash，并在严格离线模式下成功运行。
3. 最小 GPU 镜像没有 `git`。Runner 现在将该辅助 provenance 字段记为
   unavailable，同时保留确定性的 source-tree hash，并增加了回归测试。

每次重试都使用全新的输出目录，没有把 partial 结果冒充成功。

## 重要局限

- 仍然只有一个模型、一个 seed 和一个合成协议。
- 完整轨迹臂看到 6,806 个 target token，answer-only 为 4,140，前者多
  64.4%；所以这是可学习性和工程可行性证据，不是轨迹结构的因果效应。
- 训练 fixtures 符合 trajpack `DatasetExample` 契约，但不是从生产
  DeepSeek Harness 会话采集得到的真实轨迹。
- 下一项可信效用研究应采用 target-token-matched、多 seed、自有且 repo
  隔离的 coding tasks，并在 held-out 仓库上运行可执行测试。
